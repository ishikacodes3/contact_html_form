##📩 Simple Contact Form

This is a simple and beginner-friendly Contact Form created using HTML.

The form allows users to enter their name, email address, and a message.

##🛠️ Technologies Used

- HTML5
- Basic Inline CSS

##✨ Features

- Name input field
- Email input field
- Message textarea
- Send/Submit button
- Simple and clean form layout
- HTML form elements such as "form", "fieldset", "label", "input", and "textarea"
